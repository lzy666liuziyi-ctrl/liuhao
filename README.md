# 五音生乐

## 项目介绍
《五音生乐》是一个移动端优先的东方五音五行音乐生成原型，基于《黄帝内经》五音体系灵感，支持生成音乐卡片、收藏、历史、曲库筛选与文化知识浏览。

## 技术栈
- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- lucide-react
- localStorage

## 安装方式
```bash
npm install
```

## 运行方式
```bash
npm run dev
```

## 项目目录
- `src/components` 组件
- `src/data` 五行与曲库数据
- `src/pages` 页面
- `src/utils` 生成、推荐、存储逻辑

## 核心功能
- 首页 Hero、今日五音、节气推荐、场景推荐
- 分步骤音乐生成、相似曲生成、模拟播放器
- 分享海报弹窗（导出预留）
- 曲库搜索筛选
- 知音文化卡片
- 我的收藏、历史、偏好标签、关于弹窗

## 后续可扩展方向
- 接入真实音频与播放器
- 接入 AI 作曲与封面生成
- 海报导出（html2canvas）
- 小程序版本与后端账号体系

## 如何接入本地音源
1. 下载或准备你有权使用的古琴、洞箫、埙、磬音频。
2. 按照指定文件名放入 `public/samples` 对应目录。
3. 刷新网页。
4. 生成音乐时选择对应乐器。
5. 如果后续要公开上线，请检查每个音源的授权协议，并在 `audioSources.ts` 中补充作者、来源和许可证。
