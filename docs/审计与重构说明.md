# 五运六气项目审计与重构说明（更新）

## 本轮新增

1. 新增可配置节气切换日
   - `rules.boundaryConfig` 支持自定义 `dahanDay/lichunDay`。

2. 新增运行时 schema 守卫
   - `isGeneratedReport(v)`：用于校验缓存/网络反序列化数据是否可安全渲染。

3. 新增摘要格式化层
   - `format.summarizeReport(report)`：统一生成 UI/CLI 可读摘要字段。

4. 新增报告元信息
   - `GeneratedReport.meta`：包含 `engine/version/generatedAt`。
   - 便于日志追踪、排障、结果溯源。
5. 同步 CLI / demo 输出
   - CLI 摘要输出新增引擎版本。
   - demo 输出新增 `engineVersion`。
6. 扩展自动化断言
   - `generator` 与 `cli` 测试增加 `meta` 字段校验。
   - 新增 `meta-version` 测试，保证 `ENGINE_VERSION` 与 `package.json` 同步。
   - 总测试数更新为 22（新增 boundaryConfig 可配置回归测试）。
